# Student Productivity Platform

A modern, responsive web app designed to help students stay organized, focused, and productive in one place. This platform brings together essential study and productivity tools in a clean, user-friendly interface.

## Overview

Student Productivity Platform is a lightweight web application built with HTML, CSS, and JavaScript. It provides a centralized dashboard for managing daily tasks, performing quick calculations, testing knowledge with quizzes, checking the weather, and using a focus timer for study sessions.

## Features

- Responsive dashboard with a polished student-friendly layout
- Task management with pending and completed task tracking
- Interactive calculator for everyday calculations
- Quiz section for learning and self-assessment
- Weather lookup for different cities
- Focus timer to support study and productivity sessions
- Clean navigation and modern UI design

## Tech Stack

- HTML5
- CSS3
- JavaScript (Vanilla)
- Material Symbols and Google Fonts

## Project Structure

- index.html – Main dashboard entry point
- pages/ – Additional pages such as tasks, calculator, quiz, weather, timer, and settings
- CSS/ – Styling for the full application
- JS/ – Interactive logic for the different tools
- Assets/ – Images and other static resources

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/Mohamedamir2004/Student_Productivity_Platform.git
   ```
2. Open the project folder:
   ```bash
   cd Student_Productivity_Platform
   ```
3. Open index.html in your browser, or use a live server extension such as Live Server in VS Code.

## Usage

- Open the dashboard to view your productivity overview
- Use the Tasks page to manage your daily work
- Access the Calculator for quick calculations
- Try the Quiz section to test your knowledge
- Check the Weather page for city-based weather updates
- Use the Timer page for focused study sessions
